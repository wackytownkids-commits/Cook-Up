BUILD COOKUP IN THE CLOUD - STEP BY STEP
(no Terminal, only a web browser)

You'll use GitHub (a free site that lots of people use for code) to have
their Macs build Cookup.dmg for you. You never open Terminal. You only
click things in your browser.

ESTIMATED TIME: 25 minutes the first time. Most of that is waiting for
the build to run. You can do other stuff while it builds.

--------------------------------------------------
PART 1: MAKE A FREE GITHUB ACCOUNT
--------------------------------------------------

1. Open a web browser. Go to: https://github.com
2. Click the "Sign up" button in the top right.
3. Type your email, pick a password, pick a username (anything you
   want - this will appear in your repo URLs).
4. Verify your email when GitHub sends a code.
5. On the "what are you here for" questions, just pick whatever. It
   doesn't matter for this.

You now have a GitHub account. Total Terminal commands so far: zero.

--------------------------------------------------
PART 2: CREATE A PLACE FOR COOKUP'S CODE
--------------------------------------------------

6. At the top right of github.com, click the "+" button.
7. Pick "New repository" from the dropdown.
8. Repository name: cookup
9. Leave everything else at defaults. Make sure "Public" is selected
   (free Mac build minutes only apply to public repos - and "public"
   just means people CAN see your code if they know your username,
   it doesn't mean anyone will).
10. Click the green "Create repository" button at the bottom.

You're now on an empty repo page. Keep it open.

--------------------------------------------------
PART 3: UPLOAD THE COOKUP FOLDER
--------------------------------------------------

11. On the empty repo page, find the line that says
    "uploading an existing file" - it's a blue link near the middle.
    Click it.
12. In another window, open Finder (or File Explorer on Windows) and
    navigate to the Logic Plugin folder.
13. SELECT EVERYTHING INSIDE IT. Important: not the outer Logic Plugin
    folder itself, but all the stuff inside (main.js, package.json,
    the .github folder, the renderer folder, etc.). Ctrl-A / Cmd-A
    is the fastest way.
14. Drag everything onto the GitHub upload page. GitHub will show
    "Add files via upload" and list everything you dragged.
15. Scroll to the bottom. In the "Commit changes" section, the default
    message is fine. Click the green "Commit changes" button.

GitHub will upload everything. This takes 30-60 seconds depending on
your internet. A few of the files are big (the icon + assets).

IMPORTANT: the ".github" folder MUST be included. That folder tells
GitHub to build Cookup when you upload. If you don't see it in the
upload list, drag it in separately. In Finder, press Cmd-Shift-.
(period) to show hidden folders - that makes the .github folder
visible so you can drag it.

--------------------------------------------------
PART 4: WATCH THE BUILD
--------------------------------------------------

16. After the upload finishes, click the "Actions" tab near the top
    of the repo page (it's next to "Code," "Issues," "Pull requests").
17. You'll see "Build Cookup DMG" running with a yellow dot next to it.
    (Yellow = running, green check = done, red X = failed.)
18. Click it to watch progress if you want. It takes about 15-20
    minutes - a GitHub Mac is installing Python, downloading MusicGen,
    and building the DMG.
19. Go make coffee. Don't close the tab but don't stress it either -
    you can come back.

--------------------------------------------------
PART 5: DOWNLOAD THE DMG
--------------------------------------------------

20. When the build finishes, the yellow dot turns into a green check.
    Click the build name to open its page.
21. Scroll all the way down to the "Artifacts" section.
22. You'll see "Cookup-dmg" as a download. Click it.
23. Your browser downloads Cookup-dmg.zip. Unzip it - inside is
    Cookup-0.1.0-arm64.dmg.
24. Double-click the DMG. Drag Cookup into Applications.
25. Open Applications. Right-click Cookup -> Open -> Open again.
    (macOS asks this one time because we haven't paid Apple $99 for
    a signing certificate. After the first Open it launches normally.)

Done. Cookup is installed.

--------------------------------------------------
MAKING CHANGES LATER (still no Terminal)
--------------------------------------------------

When you want to change something about Cookup (colors, text, whatever),
you can edit files right on github.com:

   - On your repo page, click into the file you want to edit.
   - Click the little pencil icon in the top right.
   - Make your changes. Scroll down, click "Commit changes."
   - Go to the Actions tab. A new build will already be running.
   - When it finishes, download the new DMG from Artifacts.

Every time you commit a change, GitHub rebuilds Cookup for free.

--------------------------------------------------
TROUBLESHOOTING
--------------------------------------------------

"The build failed with a red X."
   Click into the failed run, find the step with a red X, and copy
   the error message. Paste it to me and I'll fix it.

"I don't see a Build Cookup DMG workflow running."
   The .github folder didn't upload. Go back to step 15 and make
   sure you dragged the .github folder in. You may need to show
   hidden files first (Cmd-Shift-. in Finder on Mac).

"Artifact download is empty or won't open."
   Sometimes Safari blocks .zip auto-open. Try Chrome or Firefox,
   or right-click the downloaded file -> Open With -> Archive Utility.
