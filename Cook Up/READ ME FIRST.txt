COOKUP - QUICK START (NO TERMINAL)

You're holding a folder full of source code. To turn it into a Mac app
(Cookup.dmg), you just need to double-click one file.

-------------------------------------------------
STEP 1 (ONE TIME ONLY): Install Node.js
-------------------------------------------------
Cookup uses Node.js to build itself.

   - Go to nodejs.org
   - Click the big green "LTS" button
   - Open the downloaded .pkg file, click through the installer

If you don't have Node, the build file in Step 2 will open nodejs.org for you
automatically and tell you to install it.

-------------------------------------------------
STEP 2: Double-click "Build Cookup.command"
-------------------------------------------------
   - Open the Logic Plugin folder in Finder
   - Double-click the file called "Build Cookup.command"
   - A black Terminal window opens. Leave it alone. Don't type.
   - First build takes about 15 to 20 minutes (downloads MusicGen)
   - Later builds take about 1 minute

When it's done a popup says "Cookup.dmg is ready" and Finder shows
you the file.

-------------------------------------------------
STEP 3: Install the DMG
-------------------------------------------------
   - Double-click Cookup.dmg
   - Drag Cookup into the Applications folder
   - Open Applications, right-click Cookup, choose Open, click Open again
     (macOS asks this once because we haven't paid Apple $99 for
     code signing yet. After the first Open, Cookup launches normally.)

-------------------------------------------------
IF DOUBLE-CLICK DOESN'T WORK
-------------------------------------------------
If "Build Cookup.command" won't open when you double-click it, it means
macOS turned off its execute permission (this can happen when files are
copied from Windows or a cloud drive).

The cleanest fix, no Terminal required:
   - Right-click the file -> Get Info
   - At the bottom, expand "Sharing & Permissions"
   - Click the little lock in the corner (enter your Mac password)
   - Set "everyone" to "Read & Write"
   - Close Get Info. Double-click the .command file again.

If that also doesn't work, there is ONE command in Terminal that fixes it
permanently:

   chmod +x "/path/to/Build Cookup.command"

Drag the file onto the Terminal window to auto-fill the path.
